## 🚀 Как использовать

### Без Redis (работает сразу):
```bash
npm run dev
```

### С Redis (рекомендуется):
1. Установить Redis (см. `REDIS_SETUP.md`)
2. Добавить в `.env`:
```env
REDIS_URL=redis://localhost:6379
```
3. Запустить:
```bash
npm run dev
```
